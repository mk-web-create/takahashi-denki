# 高橋電機製作所 営業提案用参考サンプル

写真追加版（2026年9月9日）。

このフォルダの `index.html` をダブルクリックし、EdgeまたはChromeで開いてください。インストール・ビルド・インターネット接続・サーバー起動は不要です。CSS・JavaScript・assetsフォルダも同じフォルダに置いたまま閲覧してください。

## 非公開について

ローカル制作専用です。公式サイトではありません。Gitリポジトリではない独立した新規フォルダに作成しました。公開、デプロイ、git push、PR作成、共有リンク発行、外部アップロード、会社への連絡は行っていません。既存ポートフォリオへの変更もありません。

`noindex,nofollow` は補助設定です。非公開を保つため、このフォルダをホスティングサービスや公開リポジトリへアップロードしないでください。

## ファイル

- `index.html`：1ページのサイト本体、写真付き事業紹介
- `styles.css`：PC・スマートフォン向けの表示
- `assets/`：表示用WebP画像4点、生成元PNG、生成プロンプト。実際の同社の写真ではありません。サイト本体は軽量なWebPだけを読み込みます
- `script.js`：モバイルメニューと送信しないデモ
- `制作メモ.md`：情報源・確認日・未確認事項・改善提案
- `verification.json`：機械的な動作確認結果
- `screenshots/desktop-top.png`：PCの冒頭（幅1440px）
- `screenshots/desktop-full.png`：PCのページ全体
- `screenshots/mobile-top.png`：スマートフォンの冒頭（幅390px）
- `screenshots/mobile-full.png`：スマートフォンのページ全体
- `screenshots/desktop-business.png` / `mobile-business.png`：写真付き事業紹介
- `screenshots/mobile-demo.png`：送信しないデモ操作後のページ全体

## 操作

上部ナビゲーション・ボタンはページ内の該当箇所へ移動します。スマートフォンでは「メニュー」で開閉します。Escapeキーでも閉じられます。

「送信デモを試す」を押すと「サンプルのため送信されません」と画面内に表示します。送信処理・サーバー処理・データ保存・添付機能はありません。入力は架空の内容でお試しください。電話番号とメールアドレスはテキスト表示のみです。

JavaScript無効時も本文とナビゲーションを閲覧できます。デモ操作時のメッセージ切り替えにはJavaScriptが必要です。

## 検証済み・検証範囲

写真追加後の2026年9月9日、WindowsのMicrosoft Edge（Playwrightによるheadless実行）で確認。

- ローカル画像4枚の読み込みと、PC・スマートフォンでの写真トリミングを確認
- 1440 / 1024 / 768 / 390 / 375 / 320px幅：横はみ出しなし、ページ内リンク先あり
- PC・スマートフォンのスクリーンショットを目視確認：明らかな文字切れ・重なりなし
- モバイルメニュー：クリック・Enter・Escape・リンク選択時の閉鎖
- デモ：キーボードで実行可能、操作によるネットワーク要求0件
- tel/mailtoリンク、form要素、Cookie、localStorage、sessionStorageなし
- ページの外部リソース要求0件、JavaScript実行エラー0件
- 640px幅・ルート文字サイズ200%：横はみ出しなし
- file:// での直接閲覧とデモ動作

検証用サーバーは `127.0.0.1:8797` のみで待ち受け、検証終了時に停止しました。外部公開トンネルは使用していません。

iPhone/Android実機、Safari/Firefox、スクリーンリーダーによる読み上げ、正式なWCAG適合監査は実施していません。200%確認はCSSルート文字サイズ変更であり、全ブラウザーのズーム試験ではありません。
